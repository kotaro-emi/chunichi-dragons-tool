# 応援歌リサーチ・まとめスキル

選手別応援歌（歌詞つき）を調べて、見やすい単体HTMLファイルとしてプロジェクトフォルダーに保存するスキル。対象球団の指定が無ければ中日ドラゴンズを既定とする。

## 手順

1. **ロースター取得**: NPB公式サイト (`https://npb.jp/bis/teams/<team>.html` 形式、中日は `rst_d.html`) などから対象シーズンの選手一覧とポジション（投手・捕手・内野手・外野手）を取得する。外国人選手は別途タグ付けする。

2. **応援歌の歌詞を収集**: 応援歌まとめサイト（例: `ouenka-shu.com`）や球団応援団の公式サイトを WebSearch → WebFetch で選手ごとに調べ、以下を抽出する。
   - 本編の歌詞（前奏がある場合は前奏も）
   - コール・シャウト部分（「かっとばせー！」など）は本文と区別して記録する
   - 個別応援歌が無い選手向けの汎用テーマがあれば併記する
   - 球団公式応援歌（例:「燃えよドラゴンズ」）のような**著作権保護された正式楽曲**は、全文を書き出さず、構成やサビの一部紹介＋出典リンクに留める（個人の応援チャント歌詞と違い、これは商用レコード楽曲のため）

3. **ポジション別に整理**: 投手 → 捕手 → 内野手 → 外野手の順にグルーピングする。外国人選手には識別タグを付ける。

4. **単体HTMLとして構築**: 外部依存なしの自己完結HTML（インラインCSSのみ、フォントは日本語システムフォントスタック `"Hiragino Mincho ProN"/"Yu Mincho"` を見出し、`"Hiragino Kaku Gothic ProN"/"Yu Gothic"` を本文に使用）で、以下を満たす:
   - ライト/ダーク両テーマ対応（`prefers-color-scheme` と `data-theme` 属性の両方に対応するCSSカスタムプロパティ設計）
   - ポジション別セクション + カード形式のレイアウト、上部にジャンプ用ナビ
   - 歌詞本文とコール部分を視覚的に区別（例: コールは色分け）
   - 末尾に出典リンクと「応援歌は移籍・成績により変更される場合がある」旨の注記を入れる

5. **保存先**: プロジェクトルート直下に `<球団名>選手別応援歌辞典.html` のようなわかりやすい日本語ファイル名で保存する（Artifactとしても見せたい場合は同内容を先に `Artifact` ツールで公開してから、同じファイルをプロジェクトフォルダーにも書き出す）。
